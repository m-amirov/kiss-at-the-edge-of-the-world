# Тест новой литературной редакции (эпизоды 1–6)

**Это не релиз-кандидат и не полная версия сезона.** В главном меню старой короткой игры появилась отдельная кнопка «Новая литературная редакция · эпизоды 1–6». Она открывает `literary.html` — интерактивное чтение всех написанных сцен S01–S26/S65/S66, включая альтернативы, один из четырёх вечеров, дальнейшее решение Алисы в S26 и соответствующие реакции. На последней сцене черновик честно останавливается: эпизоды 7–10 и финалы ещё не написаны.

## Запуск с локального компьютера

При установленном Node.js 22+ в корне проекта:

```powershell
npm run dev
```

Откройте `http://127.0.0.1:4173/`, затем указанную кнопку главного меню, либо сразу `http://127.0.0.1:4173/literary.html`. Если порт 4173 уже занят, укажите другой порт, например `$env:PORT=4174; npm run dev`.

`npm run literary:compile` пересобирает `src/literary-season-data.js` из литературных Markdown-файлов. Компилятор не дописывает эпизоды и не создаёт недостающие развилки; после изменения рукописи выполнить компиляцию и `npm run test:narrative`.

## Сохранения и безопасность

- Старая игра использует собственную схему локального/облачного прогресса, литературный черновик — отдельный локальный ключ `kiss-at-the-edge-of-the-world:literary-draft:v1`; он не загружает Yandex SDK и не перезаписывает старые сохранения.
- Настройки и облачное сохранение старой игры пока не перенесены в литературный черновик. Не публикуйте `literary.html` как новую готовую игру.
- Отсутствующие арт-ассеты не заменяются случайными чужими локациями. В ряде сцен показывается нейтральный фон; в основном игровом runtime новая сценарная версия пока не интегрирована.
- При применении патча к проекту, изменённому после предыдущей рабочей сборки, объединяйте файлы по diff, чтобы не потерять более позднюю работу Codex.

## Приёмка

`npm run test:narrative` проверяет литературный компилятор, 16 сочетаний вечера и выбора маршрута, 300 дополнительных вариаций решения и существующую старую игру/S18-preview. `npm run release:preflight` **намеренно возвращает BLOCKED и ненулевой код** до появления полного нового сезона, его графики, единого runtime и внешней QA-доказательной базы. Запуск Node/локального читателя сам по себе не заменяет проверки в браузере Яндекс Игр.
