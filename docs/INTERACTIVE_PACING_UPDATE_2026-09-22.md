# Изменения интерактивности и темпа — 22.09.2026

**Статус: рабочая сборка, НЕ релиз-кандидат.** Запрос пользователя: больше решений по ходу истории и меньше непрерывного чтения длинных диалоговых блоков. Изменения внесены в копию последнего переданного проекта; диск `E:` не изменён.

## Изменения

- Добавлено **95 уникальных написанных узлов выбора** (`Sxx-C90`/`Sxx-C91`) по всем 66 сценам, с двумя сюжетно-конкретными репликами/реакциями каждого. Эти решения не складываются механически из взаимно исключающих романтических сцен: **за одно прохождение доступно 113–116 выборов**, из них **66–68 новые**, по сравнению с прежними 47.
- Сумма доступных выборов по эпизодам при обычном романтическом вечере: **14 / 14 / 14 / 13 / 8 / 19 / 9 / 5 / 9 / 8** = 113. Для альтернативы B в эпизоде 5 доступно 9 (итого 114), для отдельного вечера Алисы — 11 (итого 116). Выборы в ветвях, которых игрок не видит, в цифры одного прохождения не включены.
- **Десять вариантов поздних откликов** на ранние дополнительные выборы; новые ответы сохраняются в прежней структуре `choices`. Большинство новых выборов меняют ближайший диалог, но не запускают отдельный сюжетный маршрут: не выдавать их за 95 разных развилок или финалов.
- Для всех исходных авторских абзацев добавлен вывод по страницам: максимум три коротких абзаца или 95 слов в одном диалоговом экране, с сохранением точного порядка и текста исходной рукописи. Длинный отдельный авторский абзац не разрезается автоматически. Кнопка **«К выбору ⇢»** добровольно пропускает остаток текущего фрагмента до ближайшего видимого решения; все более ранние решения остаются обязательными и не обходятся.
- Исправлена прежняя анимация появления, которая на каждом листании кратковременно скрывала полноэкранных персонажей. Устранён скачок индексов сохранения: schema v1 копируется в `:pre-pacing-backup`, начинает чтение с начала текущей сцены, сохраняя ранее сделанные выборы, посещённые сцены и маршрут; новые сохранения имеют schema v2. Предыдущие решения не переписываются задним числом.

## Оставшиеся ограничения

1. **Исходный объём сценария не уменьшен:** рукопись по-прежнему ~27–28 тысяч слов на маршрут; обязательное непрерывное чтение сокращено за счёт дополнительных прерываний, но без кнопки «К выбору» общее время чтения не сокращается. Кнопка позволяет игроку самому выбрать между чтением полного текста и более частым интерактивным прохождением. Литературное сокращение длинных диалогов требует отдельной редакторской проверки контекста/последствий.
2. Не завершены художественное покрытие всех 66 сцен, реальный Yandex Draft QA/SDK/cloud, независимая литературная и визуальная приёмка и измеренные прохождения по целевому хронометражу. Не объявлять release-ready.
