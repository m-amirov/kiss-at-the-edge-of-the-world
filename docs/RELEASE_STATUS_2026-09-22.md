## Фактическая реализация

- `index.html` по умолчанию запускает **единую новую литературную игру**: 10 эпизодов, 66 авторских сцен, один из четырёх маршрутов и собственный финал каждого. Доступны главное меню, продолжение, новая игра, список открытых эпизодов, настройки чтения, галерея и локальное сохранение. Для новой редакции выделен отдельный облачный ключ Yandex SDK. Облачная функциональность пока не прошла live Yandex QA.
- `literary.html` открывает ту же новую игровую редакцию, используя общий движок и сохранение. Устаревшая короткая версия 12 эпизодов сохранена **только по явному `/?legacy=1`** для безопасности прежних пользовательских сохранений; S18 preview по `/?preview=s18` по-прежнему изолирован.
- Литературный источник: эпизоды 1–2 в `content/season-1-vertical-slice-episodes-01-02.md`, 3–10 в `content/season-1-literary-episode-XX.md`. Текст преобразуется штатной командой `npm run literary:compile`, а не поддерживается в дублирующей ручной копии. Новые 7–10 — **рабочий первичный сценарный черновик**, без полного независимого редакторского аудита. Предшествующие эпизоды 1–6 сохранены.
- S26 устанавливает сознательный route lock; эпизоды 7–10 содержат четыре отдельные линии, личные сцены и концовки. Выбранный романтический вечер S17 не навязывает поздний выбор. Отказ и закрытие романтического маршрута возвращают к самостоятельной линии Алисы. Общий день прощания S48 теперь предшествует каждому индивидуальному эпилогу на месяц позже.
- Интерфейс использует существующие согласованные фоны и ключевые CG там, где они соответствуют сцене; в остальных местах — **явно нейтральную постановку**, не выдающую чужую локацию за нужную. Для полной художественной реализации 66 сцен требуются новые проверенные фоны, персонажные состояния, романтические CG и независимый visual QA.
