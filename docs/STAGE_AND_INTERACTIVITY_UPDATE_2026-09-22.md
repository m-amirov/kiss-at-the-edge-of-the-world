# Сценические персонажи и выборы — обновление 22.09.2026

**Статус: рабочая сборка, не релиз-кандидат.** Исходный пользовательский проект на диске E: не изменён. Эта копия создана из предоставленного архива `(20260922-111145)`.

## Визуальная постановка

- `assets/characters/{eric,nick,damir}-stage.png` преобразованы из RGB с чёрным фоном в настоящие прозрачные RGBA, сохранив чёрную одежду, волосы и фигуры. `alice-stage.png` уже был прозрачным и сохранён. `mix-blend-mode: screen` больше не используется для «удаления» фона.
- `src/literary-stage.js` задаёт явный состав сцены для всех 66 scene IDs. Появление/исчезновение актёров **не зависит от произвольного упоминания имени в реплике**. Для S01 персонажи выходят в кадр по фактическому знакомству, S03 начинается с одной Алисы и показывает Дамира после его появления, S18 переключается на общую группу утром следующего дня. S42 учитывает реально выбранного партнёра.
- На мобильных экранах двухперсонажная постановка увеличена; лица и крупные фигуры находятся в сцене над диалоговой панелью. Существующие CG сохраняют приоритет над stage-персонажами, чтобы не дублировать героя поверх его же крупной иллюстрации.
- Эмоциональные атрибуты — сценарно заданный *режим постановки*, а не обещание новой мимики: дополнительные отдельные выражения лиц и образы для каждой локации ещё не созданы. Изображения без подходящего локационного фона используют нейтральное оформление, а не чужой пейзаж.
