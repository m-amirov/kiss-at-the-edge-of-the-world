# Premium UI — сравнительный отчёт

Статус: три изолированных прототипа для выбора владельца проекта. Ни одна концепция не внедрена в основной runtime.

## A — Cinematic Romance

Сцена занимает весь экран; диалог живёт в низкой полупрозрачной cinematic-полосе, персонажи расположены симметрично вокруг safe-zone. Georgia-like serif используется для реплик и названия, системные действия уходят в тонкую верхнюю навигацию. На mobile панель становится нижней карточкой с крупной кнопкой продолжения, портреты поднимаются выше неё.

Ограничение: длинные реплики уменьшают свободную область; нужен строгий контроль safe-zone для широких CG.

## B — Editorial Romance

Светлая paper-like поверхность только там, где это поддерживает reading state: menu, choice и dialogue; фон и реальная фотографичность ассетов сохраняются. Выборы — вертикальная редакторская колонка с нумерацией и тонкими разделителями, галерея — ровная сетка. Mobile складывает колонку в полную ширину без имитации страниц на каждом экране.

Ограничение: светлый UI требует отдельной контрастной настройки для снежных/светлых фонов.

## C — Boutique Visual Novel

Тёмный базальтовый холст, коралловый акцент, компактные прямоугольные карточки и боковой маркер active state. Диалог — отдельная правая карточка, поэтому лица остаются открытыми; выборы и меню используют характерный модульный ритм. Mobile перестраивает карточки в нижний reachable stack.

Ограничение: боковая композиция чувствительна к узкой landscape-высоте; требуется сохранять проверку 360×640 и landscape.

## Общие состояния

Каждая ссылка демонстрирует menu, обычный dialogue, полноценную CG, choice (двойной клик на игровом экране), settings, gallery и season ending. Существующие ассеты взяты из `assets/characters`, `assets/backgrounds` и `assets/cg`.

## Технические границы

Прототип — статeless demo-поверхность: не импортирует `src/main.js`, не создаёт второй игровой runtime, не меняет сохранения, маршруты, SDK или visual-event routing. Все ресурсы локальны; production-критичные внешние зависимости отсутствуют. Системные шрифты выбраны намеренно, чтобы исключить CDN.

## Решение владельца

Финальное направление не выбирается автоматически. После выбора потребуется отдельный implementation scope и визуальный audit уже в production runtime.
