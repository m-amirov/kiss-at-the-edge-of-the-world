# Поцелуй на краю света

Рабочая версия романтической визуальной новеллы для Яндекс Игр: десять эпизодов, четыре сюжетных маршрута. **Не релиз-кандидат**: визуальная привязка к событиям сценария, мобильная композиция CG и проверка на черновике Яндекс Игр ещё требуют доработки.

## Локальный запуск

Требуется Node.js. В корне проекта:

```sh
npm run dev
```

Откройте адрес, указанный dev-сервером. Для локальной проверки:

```sh
npm run literary:compile
npm run test:narrative
npm run starter-kit:self-test
npm run yandex:requirements:audit
```

Игра и проектные материалы находятся в `src/`, `content/`, `assets/`, `docs/`. Инфраструктура проекта унаследована от Starter Kit 0.5.7; не переинициализируйте её и не изменяйте managed-файлы в обход штатного updater.

## Состояние изображений

Добавлены CG `s02-expedition-planning-iceland`, `s13-skaftafell-travelers`, `s18-hofn-dance-lights`, `s45-reykjavik-warm-montage`, `s46-airport-goodbye`, `s47-reykjavik-harbour-alice`. Эти CG не подтверждают полное художественное покрытие 66 сцен и корректность всех внутренних переходов.
