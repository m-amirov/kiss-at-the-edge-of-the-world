# Premium UI concepts

Изолированная HTML/CSS демонстрация трёх направлений. Production runtime, saves, routes, visual-event routing и Yandex SDK не подключаются и не изменяются.

## Локальный просмотр

Из корня репозитория:

```powershell
npm run dev
```

Открыть `http://localhost:4173/prototypes/premium-ui/index.html?concept=a` (или `b`, `c`). Кнопка `Показать CG` переключает полноценную сюжетную CG; двойной клик по игровому экрану открывает выбор.

## Направления

- A — `Cinematic Romance`: сцена доминирует, стеклянная диалоговая полоса и кинематографичная типографика.
- B — `Editorial Romance`: светлая книжная полоса, журнальная сетка и editorial-логика выбора.
- C — `Boutique Visual Novel`: компактные карточки, боковой акцент и более характерная навигация.

Все изображения — существующие локальные ассеты проекта. Для текущей типографической лаборатории добавлены локальные OFL-шрифты; внешний CDN и UI-библиотеки не используются. Подробности — в `docs/PREMIUM_UI_TYPOGRAPHY_REPORT.md`.
